A&E Learning Group | Madadeni Provincial Hospital
A mobile-first, high-performance clinical resource hub designed for Emergency Department doctors, residents, and medical students. This site serves as a centralized gateway to FOAMmed (Free Open Access Medical Education), curated YouTube playlists, and internal clinical protocols.

🩺 Purpose
The A&E Learning Group website was created to bridge the gap between high-pressure clinical shifts and continuous medical education. It provides "just-in-time" learning resources that can be accessed in seconds in the Resus bay or during quiet moments on call.

✨ Key Features
Glassmorphism UI: A modern, high-contrast design optimized for visibility under hospital fluorescent lighting.

Intelligent Search: A custom JavaScript search engine on the Menu page that uses hidden clinical tags (e.g., searching "STEMI" finds the Ischaemia module).

Single-CSS Architecture: Refactored from multiple legacy stylesheets into a single, high-performance main.css for lightning-fast loading on hospital Wi-Fi.

Mobile-First Design: Large touch targets and responsive video embeds for one-handed use during active shifts.

Integrated Resources: Direct links to Google Drive for offline PDF protocols and YouTube for video-based case reviews.

📂 Project Structure
The site is organized into clinical categories:

/basicsecg/ - Foundations of ECG interpretation.

/ischaemia/ - High-stakes STEMI and NSTEMI patterns.

/resus/ - ACLS/PALS algorithms and critical care.

/ultrasound/ - POCUS scanning guides and "knobology."

/protocols/ - Local hospital guidelines and management flowcharts.

/student/ - Peer-led resources for medical students.

🛠️ Tech Stack
HTML5 - Semantic structure for accessibility.

CSS3 - Custom properties (variables) and Flexbox/Grid layouts.

JavaScript - Lightweight search filtering and UI interactions.

FontAwesome - Clinical and social iconography.
